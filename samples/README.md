วางรูปถ่ายใบเสร็จค่าไฟของพี่เองไว้ในโฟลเดอร์นี้ (เช่น bill1.jpg, bill2.jpg)

- ถ่ายเอง 5-10 ใบพอ ไม่ต้องใช้ของลูกค้า/บริษัท
- ถ่ายเฉพาะส่วน "ใบแจ้งค่าไฟฟ้า" (โลโก้ ลงมาถึงบรรทัด Due Date) — ถ้าติดใบเสร็จของเดือนก่อนที่พิมพ์อยู่ด้านล่างมาด้วย โมเดลมักไปอ่านตัวเลขจากใบเสร็จแทน
- เบลอ/ขีดฆ่าเลขผู้ใช้ไฟออกก่อนอัปขึ้น GitHub ได้ ถ้าไม่อยากโชว์
- โฟลเดอร์นี้ gitignore รูปจริงไว้แล้ว (ดู .gitignore) — ถ้าจะ commit รูปตัวอย่างที่เบลอแล้ว ต้องใช้ `git add -f samples/<ไฟล์>`

วัดความแม่น:

- ใส่ค่าที่ถูกต้องของแต่ละรูป (อ่านด้วยตา) ใน `labels.json` ตามรูปแบบ `labels.example.json` — `labels.json` ถูก gitignore เพราะมีเลขบัญชีจริง
- รัน `python evaluate.py` ทุกครั้งที่แก้ prompt หรือเปลี่ยนโมเดล

`reference/` = รูปที่ไม่ใช่บิลจริง (เช่น อินโฟกราฟิกอธิบายบิล PEA) ใช้ดูตำแหน่งช่องต่างๆ เท่านั้น ห้ามใช้เป็นชุดทดสอบ และไม่ commit (ลิขสิทธิ์ของเจ้าของภาพ)
